Rapid Development

A completely open-source modern rapid development platform that helps developers efficiently build high-quality backend systems, reducing repetitive work and improving development efficiency.

🛠️

Full-Stack Integration

Frontend-backend separation architecture, integrating Python (FastAPI) + Vue3 + TypeScript for multi-platform unified development, providing a one-stop out-of-the-box experience.

🧱

Modular Design

System functions are highly decoupled, easy to extend and maintain, following development specifications and design patterns, supporting plug-in development.

⚡️

High Performance

Using FastAPI asynchronous framework + Redis cache to optimize interface response speed, improve system performance, and support high concurrency scenarios.

🔒

Security Authentication

Supports JWT OAuth2 authentication mechanism, RBAC model implements fine-grained permission control at the menu, button, and data levels to ensure system security.

🚀

Quick Deployment

Supports Docker/Docker Compose/Nginx one-click deployment, reduces operation and maintenance costs, and supports multi-environment configuration management.

📊

Rich Built-in Modules

Includes multiple core modules such as system management, monitoring management, and public management to meet enterprise-level application needs.

🎨

Beautiful UI Design

Built based on ElementPlus and Wot Design Uni, providing modern, responsive user interfaces.

📱

Multi-platform Support

Supports both Web and mobile (FastApp) platforms, providing a consistent user experience.

📖

Comprehensive Documentation

Provides detailed Chinese development documentation and usage guides, reducing learning costs and accelerating project implementation.
